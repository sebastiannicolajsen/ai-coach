# Panel: AI Fluency Coach (Claude Code mod)

Last updated: 2026-10-07 · 6 seats

## Line — newcomer, first hour in Claude Code (stress-test)
- **Who:** 27, two weeks at Implement, comes from a strategy background. Has used Claude chat, never a terminal tool. Installed the coach because onboarding told her to.
- **Catches:** anything that assumes she knows the framework, the terminal, or what a station is. UI that asks for attention she doesn't have mid-task.
- **Test:** The first-hour test — after one hour, can Line say what the coach is for without having read anything?
- **Family:** stress-test
- **Voice:** Polite, a bit lost. "There are four words at the top and I don't know if I'm supposed to click them."

## Jonas — daily Claude Code power user (audience)
- **Who:** TTC developer, lives in Claude Code, runs long agentic sessions, hates latency and noise.
- **Catches:** friction, chatter, anything that slows the expert path or repeats advice he already follows.
- **Test:** The tenth-session test — is the coach still welcome in session ten, or has he switched it off?
- **Family:** audience
- **Voice:** Terse. "Third time it tells me to check the output. I just ran the tests."

## Dr. Holm — learning scientist (craft)
- **Who:** Researcher in feedback and scaffolding; has read Kluger & DeNisi and the expertise-reversal literature.
- **Catches:** feedback aimed at the person, scaffolds that never fade, help that replaces the thinking it should train.
- **Test:** The fade test — what does the coach do when the user already shows the behaviour?
- **Family:** craft
- **Voice:** Measured. "Handing over the finished question is help, not learning. Where is the fade?"

## Maya — Anthropic product designer, Claude Code (craft)
- **Who:** Designs first-party Claude Code surfaces; guards restraint, hierarchy and native feel.
- **Catches:** competing surfaces, colour noise, anything that reads as a third-party plugin or as Claude-generated UI.
- **Test:** The first-party test — could this ship in the Claude Code changelog without anyone noticing it wasn't built in-house?
- **Family:** craft
- **Voice:** Calm and exact. "Five surfaces each want my eye. Which one is the one?"

## Karl — partner, never heard of the 4D framework (fresh-eyes)
- **Who:** Senior partner in an adjacent practice, sceptical of AI tooling, will decide whether his team uses it.
- **Catches:** framework jargon, leaps the designers stopped noticing, concepts that only make sense with the diagram in your head.
- **Test:** The so-what test — in one sentence, what does this change in how my people work?
- **Family:** fresh-eyes
- **Voice:** Dry. "Why is my prompt suddenly called a 'brief'?"

## Henriette — IT security and DPO (constraint)
- **Who:** Owns data protection and tool approval at Implement; works with public-sector clients under GDPR.
- **Catches:** unscoped data flows, stored client text, cost surprises, unsandboxed code.
- **Test:** The client-data test — if a session contains client data, where does every copy of it end up?
- **Family:** other
- **Voice:** Unhurried, specific. "The context card holds the client's name. Where is it stored, and for how long?"

## Notes
- Built for the post-build critique of the Coach design (rail, gutter marks, band, station focus, cost reveal).
- Expected tension: Jonas (less) vs Line (more guidance). Resolve with the ease-in and fade rules, not by averaging.
