# AI Coach

<a href="dist/coach-0.2.0.zip"><img src="https://img.shields.io/badge/Download-Coach%200.2.0-2A9D8F?style=for-the-badge" alt="Download Coach 0.2.0"></a>

**Coach** is a Claude Code mod that helps people work well with Claude. It follows the loop of Plan, Brief, Review and Own, shows which step each message belongs to, and gives short, grounded suggestions for the next one.

- **Download:** [`dist/coach-0.2.0.zip`](dist/coach-0.2.0.zip)
- **How it works, commands, settings and install:** [`coach/README.md`](coach/README.md)

Install from this repository:

```bash
claude plugin marketplace add /path/to/ai-coach
```

```bash
claude plugin install coach@ai-coach
```

Then start a new chat and run `/coach help`.

Based on the AI Fluency Framework by Dakan, Feller and Anthropic, CC BY-NC-SA 4.0.
